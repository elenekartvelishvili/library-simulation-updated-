# Library Simulation System

A console-based C# application that simulates core library management operations such as book borrowing, returning, and user interactions.

The project was developed to strengthen understanding of object-oriented programming, system design, collections, and structured application development in C#.

## Features

- Add and manage books
- Borrow and return book functionality
- Track library inventory
- User interaction through console interface
- Object-oriented system design
- Structured class organization

## Technologies Used

- C#
- .NET Console Application
- Object-Oriented Programming (OOP)
